# 柏宝绘 · 划线出图

[柏宝绘](https://github.com/baibai-git/ST-BaiBai-Image) 的配套小插件：**在聊天正文里选中一句话，点「画这句」，柏宝绘就在这句所在的段落后面配一张图。**

## 使用

1. 在任意楼层的正文里用鼠标划选（手机长按选择）一句话。
2. 选区下方会浮出一个 🎨「画这句」按钮，点它。
3. 插件用 API（默认跟随柏宝绘「生成 tag」指派的副 API）把这句话写成生图提示词（会参考本楼正文、上一楼、柏宝绘角色外貌库）。
4. 弹窗里可以检查、修改提示词，或者写一句补充要求让它「重写」。
5. 点「插入并生成」：一个柏宝绘图片卡片会出现在这句话所在段落的下面，并自动开始出图。

生成出来的就是柏宝绘自己的图片卡片，所以重绘、编辑提示词、看大图、图库归档都和柏宝绘自动配的图一样。提示词藏在 `<bbi_image>` 标签里，不会显示在正文，也不会发给主模型。

## 前提

- 已安装并配置好**柏宝绘**（出图渠道能正常出图）。
- SillyTavern 1.12.13 或更新版本。

## 安装

**方法一：放到 GitHub 上（推荐，方便以后更新）**
1. 在 GitHub 新建一个公开仓库（比如 `ST-BaiBai-SelectDraw`），把这个文件夹里的文件全部上传到仓库根目录。
2. 在酒馆「扩展 → 安装扩展」里填入仓库地址。

**方法二：直接拷贝文件夹**
把整个 `ST-BaiBai-SelectDraw` 文件夹放到：
`SillyTavern/data/default-user/extensions/`（换成你的用户名文件夹）
或旧版的 `SillyTavern/public/scripts/extensions/third-party/`，然后刷新酒馆。

## 设置

在「扩展」面板里找到「柏宝绘 · 划线出图」：

| 设置 | 说明 |
| --- | --- |
| 写 tag 用的 API | 默认「跟随柏宝绘」：柏宝绘「生成 tag」用哪个副 API 就用哪个，没指派则用酒馆主 API。也可以单独选某个副 API 或固定用主 API |
| 给发型、发色、瞳色加权 | 外貌 tag 自动加权（NAI 写成 `1.3::short hair::`，ComfyUI 写成 `(short hair:1.3)`），防止画师串 / vibe 把发型带跑 |
| 破限 / 附加 system 提示 | 副 API 拒答时用 |
| 插入前先让我确认 | 关掉后一点就直接插入出图 |
| 插入后自动开始出图 | 关掉后只插卡片，自己点「生成图片」 |
| 同时写自然语言描述 | ComfyUI 工作流用到 `%nl%` 时打开 |
| 把上一楼也发给模型 | 帮助判断人物、场景 |
| 多角色提示 | NAI 4.5 / V5 时把每个角色分开写，减少串色 |
| 本楼正文最多发送字数 | 以划线句子为中心截取 |
| 额外规范 | 你自己的画面要求，附加在系统提示后 |

## 文件

- `index.js`：界面与酒馆、柏宝绘的对接
- `lib.js`：定位句子、插入标签、组装提示词等纯逻辑
- `style.css`：浮动按钮与弹窗样式
